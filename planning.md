# Project Proposal

## Business Case

### Problem statement
Finding public toilets in Bristol can be difficult for residents and visitors, especially for people who need accessible facilities. Information about toilet locations and opening hours can be difficult to find in one place.

Bristol Toilet Finder aims to make this information easier to access. It uses public toilet data from Open Data Bristol to provide a searchable list of toilets, including addresses, opening hours and available facilities. Users can search for toilets and filter the results to find facilities that meet their needs.

### Business benefits
The Bristol Toilet Finder will provide several benefits:

- **Saves time:** Users can search for public toilets in Bristol without checking multiple websites.
- **Improves accessibility:** Users can filter facilities to find toilets marked as having disabled access.
- **Easy to use:** The website provides toilet addresses and opening hours in one place.
- **Supports visitors and residents:** People can use the information to plan their journeys.
- **Uses open data:** The project makes public information from Open Data Bristol easier to search and understand.

### Options Considered
Three options were considered for helping people find public toilets in Bristol:

- **Option 1: Search online using different websites.** Users can search for toilet information on general websites, but they may need to visit several pages to find addresses, opening hours and facilities.
- **Option 2: Use a static list of public toilets.** A simple list can show locations and details, but it may be harder to find a suitable toilet if the list does not include search or filter features.
- **Option 3: Build Bristol Toilet Finder.** This website uses Open Data Bristol to provide a searchable list of public toilets. Users can search for toilets and filter the results by facilities.

Bristol Toilet Finder was selected because it brings the information together in one place and provides search and filter features. The information depends on the available dataset and may not always reflect current conditions.

### Expected Risks
The main risks of the Bristol Toilet Finder project are:

- **Outdated information:** Toilet locations and opening hours in the dataset may change. Users could receive incorrect information if the data is not updated.
- **Incomplete data:** Some toilet records may have missing information about opening hours or facilities.
- **Technical problems:** The website may not work correctly on some devices or web browsers.
- **Accessibility problems:** Some users may find the website difficult to use if the text is too small or the design is unclear.
- **Limited project time:** There may not be enough time to add every possible feature before the deadline.

These risks can be reduced by checking the dataset, testing the website, using a clear design and focusing on the main required features.

## Project Scope
The scope of the Bristol Toilet Finder project is to create a simple HTML web application that helps users find public toilets in Bristol using open data from Open Data Bristol.

The system will include:

- A searchable list of public toilets.
- Toilet names, addresses and opening hours where this information is available.
- Filters for facilities, such as disabled access and baby changing.
- A clear and simple interface that users can navigate easily.
- Information from the downloaded public toilets dataset.

The project will not include live toilet availability, real-time opening-hour updates or user accounts. The accuracy of the information depends on the dataset provided.

The main users are Bristol residents, visitors and people looking for public toilet facilities.
